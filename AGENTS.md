# CaptureShield project rules

- Deliver completed, verified changes through the private repository `naivee2000/capture-shield-lab`. The user has explicitly authorized ongoing commits and pushes for this project. Summarize changes and validation before committing; verify the remote commit after pushing.
- A delivery must build from a clean clone on another supported Apple Silicon Mac. Keep scripts portable; never depend on this checkout's absolute path.
- Keep authentication data, cookies, real conversations, meeting invitations and raw capture evidence out of Git. Each computer signs in and grants its own system permissions.
- Distinguish source/build reproducibility, ChatGPT usability and capture compatibility. Never infer local visibility or meeting success from a captured image alone.
- Preserve the synthetic lab and independent recorder. Capture tests must not use the real ChatGPT website data store.
- Use Chinese for user-facing progress, English for repository documentation and UI. Preserve user changes and avoid destructive Git operations.
