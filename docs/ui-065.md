## Behavior

- **Always on Top** defaults on, is saved independently of Normal/Legacy, and keeps the panel visible while another application is used. It follows Spaces and eligible native full-screen application spaces. Turning it off restores normal stacking. This does not place the panel above every system/security surface.
- **Command-Shift-M** shows the retained chat and focuses a uniquely recognized composer. Hiding releases keyboard focus; a deliberate switch to another application is not replaced with an older application merely because the panel is hidden.
- Chat windows use a fixed public [nonactivating panel style](https://developer.apple.com/documentation/appkit/nswindow/stylemask-swift.struct/nonactivatingpanel). Pinning changes the level and [Space participation](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/canjoinallapplications), without changing the creation-time activation style. Keyboard focus is separated from application activation to avoid the ordinary inactive-application tint.
- Normal/Legacy sharing settings, content opacity, background transparency, existing WebView/session, draft, attachments and undo are retained. Popups use the same panel policy. Explicit close, minimize and hide remain available. Private Cursor is still an offline experiment.

## Repairs found during acceptance

1. AppKit's document-window ordering list omitted the new panels. Mode changes now include every owned visible surface before restoring Normal, preserving the existing WebView and draft. Capture eligibility is applied after pin appearance.
2. NSPanel's default unhandled Escape closed the chat. The panel now consumes cancellation only after editing responders have had their turn. Local checks confirmed Escape keeps the chat/draft while native confirmation sheets still cancel.
3. UI tests now resolve stable surface identifiers because panels appear as accessibility system dialogs. Focus keys are sent through the already-foreground background test application; input destination, foreground PID and panel key state remain asserted. Targeting CaptureShield itself activated it during XCTest input and was not a valid nonactivation test.
4. Popup checks explicitly expose the zoomed button before clicking its current bounds. Metadata combines AppKit inventory with application-owned windows, and actual popup accessibility presence is also required. Native resize gestures cross the minimum boundary; the 640×480 assertion remains unchanged.

Earlier failed runs were never relabeled as passes. The shared native host once exited without a completion summary; explicit fresh-host scheduling now runs all cases once and rejects incomplete output. A separate event-posting experiment lacked CI authorization and was removed without changing permissions. Long per-character focus fixtures hit the orchestration deadline; short unique markers preserve the same assertions, with a bounded fifteen-minute round budget and no retries.
