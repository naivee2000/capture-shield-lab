# Packaged UI review — 0.6.4 / build 13

This review keeps the application deployment minimum at Apple Silicon macOS 15.6. The automated review range is 15.8.2 through 27.x. It does not certify every patch in that range, future operating systems, real ChatGPT services or meeting-receiver visibility. Use [the portable UI workflow](ui-validation.md) and the repository-local [compatibility skill](../.agents/skills/capture-shield-compatibility/SKILL.md) to repeat the checks after an update.

## Changes

- A separate XCTest project launches the existing SwiftPM-packaged application with `XCUIApplication(url:)`. It does not compile an alternative app implementation.
- Isolated application identifiers, preferences, attachment directories and a nonpersistent offline WebKit store keep personal sessions out of the tests. Deterministic speech fixtures exercise the transcription interface without capturing audio or recognizing speech.
- Stable accessibility identifiers support bounded waits and native macOS mouse/keyboard actions. The image scenario verifies decoded cropped pixels and visible attachment counts after the real preview/coordinator/WebKit file handoff, including three consecutive images, deletion and re-addition. Draft and send-count assertions remain enabled.
- **Application repair:** compact-toolbar overflow entries now have working actions/submenus. Previously the Page size overflow entry could not change zoom. Mode selection remains prioritized at small widths; single-button overflow actions also remain usable.
- Owned chat windows reapply their configured sharing mode around the existing public AppKit ordering hook. This preserves the pre-display Legacy write and reconciles the state after a restored window is ordered. System panels still retain their separate original-setting restoration path. The optional JavaScript confirmation callback explicitly exports its Objective-C delegate selector across SDK annotation differences.
- The runner rejects missing prerequisites, wrong application identities, zero/skipped/partial UI execution and unsafe cleanup. A deliberate absent-control check must fail separately; it cannot turn a missing permission or zero tests into a successful negative control.

## Device checks still required

- Real ChatGPT screenshot → crop → visible attachment, existing draft/images, delete/re-add and a manually sent harmless question. No automatic sending is authorized by this suite.
- Real selected-application audio filtering, English/Mandarin models, speech quality and interruption/recovery. The blue/purple capture indicator investigation remains deferred.
- Physical Pinyin composition, candidate paging/selection and first-appearance frames. Synthetic composition flags and committed Unicode text do not test the system candidate UI.
- Independent Teams desktop sender / Chrome receiver: three full-display trials of Normal versus Legacy, background continuity, other windows, popup/candidate visibility and mode transitions. Record exact OS/build and client versions. Private Cursor remains an offline experiment.
- Physical background/content rendering on the target display, permissions and the intended global-shortcut environment. Hosted sharing attributes and Dock policy do not prove receiver privacy.

Keep these outcomes separate from automated UI results. Raw screenshots, audio, chat content and xcresult attachments are not repository artifacts.
